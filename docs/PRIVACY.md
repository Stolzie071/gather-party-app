# Приватность

Здесь описано поведение Gather v1.0 для демонстрации и тестирования. При коммерческой публикации приложения документ необходимо дополнить полноценной юридической политикой конфиденциальности под требования площадки распространения.

## Какие данные хранятся

Gather использует локальный подход. На устройстве могут сохраняться:

- настройки приложения;
- имена и аватары игроков;
- копии выбранных или сделанных пользователем фотографий;
- пользовательские наборы слов;
- состояние незавершённой партии;
- история игр и рассчитанная на её основе статистика.

Версия 1.0 не требует аккаунта и не использует сервер приложения для отправки этих данных.

## Разрешения

Доступ к фотографиям, камере и медиатеке запрашивается только после выбора связанного действия: установки фотографии игрока, создания снимка или сохранения изображения в галерею.

## Удаление данных

Игрока можно удалить вместе с его статистикой. Пользовательские наборы и сохранённые приложением фотографии также можно удалить. В отладочной сборке присутствуют дополнительные инструменты очистки локальных данных, которых нет в релизной версии.

## Интернет

Для основной игры подключение к интернету не требуется. Интернет используется внешними сервисами только при загрузке APK, просмотре репозитория и других действиях, которые пользователь выполняет за пределами приложения.
