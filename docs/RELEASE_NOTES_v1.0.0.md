# Gather v1.0.0

Первая публичная тестовая версия Gather для Android.

## Что входит в релиз

- Полный игровой цикл «Шпиона» от настройки до сохранения результата.
- Встроенные категории и наборы, включая 62 иллюстрированные локации.
- Создание, редактирование, удаление и выбор пользовательских наборов.
- Сохраняемые профили игроков с готовыми аватарами и собственными фотографиями.
- Настройка игроков, шпионов, таймера и знания шпионами друг друга.
- Приватная раздача ролей, режим без таймера, виброотклик и защита от случайного выхода.
- История партий, статистика игроков, поиск, фильтры и сортировка.
- Русская и английская локализация интерфейса.
- Адаптивное расположение элементов для компактных и больших экранов.

## Файлы для установки

- `Gather_v1_signed_arm64.apk` — рекомендуемый вариант для большинства современных Android-телефонов.
- `Gather_v1_signed_universal.apk` — запасной вариант с поддержкой нескольких архитектур.

Минимальная версия: Android 7.0 (API 24).

## Установка

1. Сначала скачайте ARM64 APK; universal потребуется только в случае несовместимости устройства.
2. Откройте скачанный файл на телефоне.
3. Если Android запросит разрешение, разрешите установку из используемого браузера или файлового менеджера.
4. Следующие версии Gather с той же постоянной подписью смогут устанавливаться поверх текущей без удаления локальных данных.

## Известные ограничения

- Полноценные правила запланированы после v1; сейчас кнопка правил показывает временное сообщение.
- Alias и «Мафия» отображаются как неактивные игры с пометкой «Скоро».
- Тёмная тема, музыка и звуковые эффекты запланированы после v1.
